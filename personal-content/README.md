# Gnanomics — Personal Content

> ⚠️ This branch holds personal content-creation assets. **Do not merge to `main`.** It is unrelated to the kiro-gateway project.

## Files

- **`stock-market-roadmap.html`** — Interactive 365-topic stock market learning roadmap with progress tracking, designed as an Instagram content planner for `@gnanomics`.

## How to download

### Option 1 — Direct download (easiest)

Click the **raw** button on GitHub when viewing the HTML file, or use this URL pattern:

```
https://raw.githubusercontent.com/<owner>/<repo>/personal/gnanomics-content/personal-content/stock-market-roadmap.html
```

Right-click → "Save link as" → save as `.html` → double-click to open in any browser.

### Option 2 — Clone the branch

```bash
git clone -b personal/gnanomics-content https://github.com/<owner>/<repo>.git
```

## How to use

1. Open `stock-market-roadmap.html` in Chrome / Edge / Firefox.
2. Click any level to expand its topics.
3. Tick off topics as you publish Instagram posts.
4. Progress auto-saves in your browser (localStorage).
5. Use the **Export** button to back up progress as JSON.
6. Use the **Print / PDF** button for a physical reference.
